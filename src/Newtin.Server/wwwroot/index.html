Herramientas

Color

Haz clic en la pizarra, escribe y pulsa Ctrl + Intro (o haz clic fuera) para fijar el texto. Con «Seleccionar», doble clic para editarlo.

Color de la nota

Haz clic en la pizarra para crear la nota.

Historial

Vista

Ctrl + rueda: zoom. Espacio + arrastrar, botón central o «Mover vista»: desplazar.
